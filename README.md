# 💒 Website de Casamento

Projeto desenvolvido como parte da disciplina **Desenvolvimento Web Client**.  
Trata-se de um **site simples de casamento**, criado para apresentar informações sobre o evento, os noivos e detalhes do grande dia, com foco em praticar conceitos fundamentais de **HTML**, **CSS** e **JavaScript**.

---

## 🌸 Objetivo do Projeto

O principal objetivo foi aplicar os conhecimentos adquiridos em **desenvolvimento web front-end**, criando uma página temática e funcional com estrutura semântica, estilos personalizados e interatividade básica.

---

## 🧱 Estrutura do Site

O website contém as seguintes seções:

- **Página inicial:** Apresentação do casal e contagem regressiva para o casamento
- **Sobre nós:** Para explicar o objetivo do site
- **Galeria de fotos/Inspirações:** Espaço para exibir fotos do casal  
- **Contato:** Links para redes sociais ou meios de comunicação

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** — estrutura da página  
- **CSS3** — estilização e layout  
- **JavaScript** — interatividade e validação de formulários  
- **Bootstrap (planejado)** — framework para aprimorar o design e responsividade
